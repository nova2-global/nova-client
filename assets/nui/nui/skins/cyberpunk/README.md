# The cyberpunk skin

Body class `skin-cyberpunk`: the themes in `nui/theme/themes.json` whose `body`
names it put it on every NovaUI document. Made by `tools/nui_new_theme.py
--skin-local`; `docs/ui/AUTHORING.md` ("Adding a theme", "Skins" and "Player
colors") says how to finish it. The skin keeps its palette and tokens here.

| File | What |
|---|---|
| `tokens.json` | The skin's palettes (`palettes`), its own tokens (`skin`: `cyberpunk-...` and shared overrides), its color slots (`slots`), extra contrast pairs (`pairs`) and the themes of its palettes (`themes`) |
| `cyberpunk-tokens.rcss`, `colors.json` | Generated from `tokens.json` by `python tools/nui_tokens.py`, which checks the contrast; do not edit |
| `art.json` | The manifest of the skin's few art pieces (empty until it has some) |
| `cyberpunk-sprites.rcss` | The sprite sheets of that art (a stub until then) |
| `cyberpunk.rcss` | The component rules |
| `windows/<window>.rcss` | A window's own rules for this skin, applied after the window's sheets |

- Every selector starts with `.skin-cyberpunk` (the scheme of "Classic skin" with
  this class) and takes the exact modern selector it overrides behind it.
- Motion only on the chrome hooks (`.nui-chrome--<part>.nui-anim`), transform
  and opacity only, values written out ("Motion and reduced motion").
- Colors come from the palette and the skin's tokens, lengths in `dp`.
